# YoMi 飞书端配置步骤

> 目标：基于飞书官方 SDK（`lark-oapi`）开发，通过官方**长连接（WebSocket）**订阅方式收发事件与卡片回调。
> **无需公网域名/IP，也不需要内网穿透**；仅需运行 YoMi 的机器可访问公网（出站）。
> 说明：长连接目前仅支持**企业自建应用**。

## 1. 创建企业自建应用

1. 打开飞书开放平台开发者后台：<https://open.feishu.cn/app>。
2. 点击「创建企业自建应用」；填写应用名称（如 YoMi 助手）、图标、描述后创建。
3. 进入「凭证与基础信息」，复制 **App ID** 与 **App Secret**，填入项目 `.env`：
   - `FEISHU_APP_ID=cli_xxxx`
   - `FEISHU_APP_SECRET=xxxx`

## 2. 开启机器人能力

进入「应用能力」→「添加应用能力」→ 添加 **机器人**（接收/发送单聊消息、发送卡片消息的前提）。

## 3. 申请 API 权限

进入「开发配置」→「权限管理」→「API 权限」，开通以下权限并发布：

| 用途 | 权限名称 | 权限点 |
|---|---|---|
| 接收用户发给机器人的单聊消息 | 读取用户发给机器人的单聊消息 | `im:message.p2p_msg:readonly` |
| 以应用（机器人）身份发送消息/卡片 | 以应用的身份发消息 | `im:message:send_as_bot` |
| 读写多维表格 | 查看、评论、编辑和管理多维表格 | `bitable:app` |
| （按需）在回调/事件中识别操作者 | 获取用户基本信息 | `contact:user.base:readonly` |

> 如后续需要接收群聊 @ 消息，再补 `im:message.group_at_msg:readonly`。

## 4. 配置事件订阅（长连接）

1. 进入「开发配置」→「事件与回调」→「事件配置」。
2. 编辑「订阅方式」，选择 **使用长连接接收事件**（**先不保存**，见第 6 步顺序）。
3. 在「已添加事件」中「添加事件」→ 选择 **接收消息 v2.0**（事件类型 `im.message.receive_v1`）。

## 5. 配置卡片回调订阅（长连接）

1. 仍在「开发配置」→「事件与回调」，打开「回调配置」页签。
2. 选择 **使用长连接接收回调**（不需要填写 URL）。
3. 「添加回调」→ 添加 **卡片回传交互回调（新版）**（`card.action.trigger`）。
   - 只添加新版即可；不要重复添加旧版 `card.action.trigger_v1`，否则会收到两路回调。

## 6. 发布应用并设置可用范围

1. 进入「应用发布」→「版本管理与发布」→「创建版本」。
2. 在版本信息中把 **可用范围** 设置为包含你自己（或全员/指定部门）。
3. 保存并发布（企业管理员审核通过后生效）。
4. **回填配置顺序**：先启动 YoMi 服务（其中基于 `lark-oapi` 的 `lark.ws.Client` 会主动建立长连接），确认日志出现长连接成功，再返回第 4 步保存「使用长连接接收事件」订阅方式；回调页签同理。保存后再发布一次新版本使配置生效。

## 7. 准备飞书多维表格

YoMi 需要 **1 个多维表格 base** 内含 5 张数据表，字段与类型须与 `app/data/tables.py` 一致：

| 表 | 唯一字段 | 主要字段 |
|---|---|---|
| 工作目标表 | 目标单位 | 长期目标、月度目标、本周目标、周起始、周结束、状态、备注、更新时间 |
| 工作规范表 | 规范名称 | 周报格式、汇报风格、必要字段、企业/团队要求、更新时间 |
| 日报总表 | 日期 | 项目、本周目标、状态、任务、实际产出、下一步、遇到的问题、计划外工作、工作负担、相关资料、原始记录、AI整理、AI简要分析、确认状态、更新时间 |
| 周报总表 | 周期 | 周起始、周结束、本周目标、工作成果、问题处理、下周重点、工作分析、改进建议、原始记录、用户反馈、反馈状态、更新时间、能力评分_Agent开发、能力评分_技术能力、能力评分_产品能力、能力评分_项目交付、能力评分_表达沟通 |
| 能力画像表 | 月份 | 当前能力状态、主要优势、主要问题、改进方向、下一阶段建议、分析文字、更新时间、能力评分_Agent开发、能力评分_技术能力、能力评分_产品能力、能力评分_项目交付、能力评分_表达沟通 |

操作步骤：

1. 在飞书创建 1 个多维表格（网址以 `/base/` 开头），在其中创建上述 5 张表并建立字段。
2. 为 YoMi 应用授权该 base：打开该多维表格 → 右上角「···（更多）」→「添加文档应用」→ 搜索并添加 YoMi 应用 → 授予 **可管理** 权限（应用需先在第 3 步开通至少一个多维表格 API 权限后才能被搜索到）。
3. 复制各表 ID 与 base token 填入 `.env`：
   - URL 形如 `https://xxx.feishu.cn/base/APP_TOKEN?table=tbl_xxx`
   - base token 取 `APP_TOKEN`（对应 `BITABLE_APP_TOKEN`）
   - 每张表的 `tbl_xxx` 分别填入对应的 `BITABLE_*_TABLE_ID`

## 8. 获取接收人 open_id

1. 服务运行并建立长连接后，在自己与 YoMi 机器人的单聊中发送任意一条文本。
2. 从 `im.message.receive_v1` 事件中的 `event.sender.sender_id.open_id` 获取你的 `open_id`。
3. 填入 `.env`：`FEISHU_USER_OPEN_ID=ou_xxxx`。

## 9. 验证清单

- [ ] `.env` 已填 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`BITABLE_*`、`FEISHU_USER_OPEN_ID`
- [ ] 服务启动日志显示长连接已建立（如 `connected to wss://...`）
- [ ] 打开与机器人单聊，可收到 YoMi 主动发送的测试消息/日报卡片
- [ ] 点击/提交卡片后，服务日志出现 `card.action.trigger` 回调且 3 秒内成功响应
- [ ] 程序能读取/写入多维表格（连通性自检通过）
