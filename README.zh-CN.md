### 少写报告，多看成长

把「晚点再写」变成「已经记好了」。

一个长在飞书里的个人工作助手：22:00 推送**极简填写卡片**，几句要点由 AI **串联成连贯短句**，
产出含糊时**只追问一句**，再用**周报、用户反馈与月度能力画像**闭环沉淀。

> **MVP 范围：** 单用户、交互全部在飞书内完成。LLM 层保持 **OpenAI 兼容接口**，
> 模型不可用时自动回退为你填写的原始表达，数据不丢。

**核心亮点**

- 🪶 **极简填写**：卡片只收"要点 + 产出"分点，非必要内容折叠收起
- ✨ **AI 串联成句**：把零散要点写成连贯短句（≤35 字），不虚构、不扩写
- 🔍 **关键缺失追问**：产出含糊时主动追问一句，补充后自动重新整理
- ✅ **确认 / 重新生成**：不满意可填意见重新生成；不操作则默认保存
- 📊 **周报 → 反馈 → 画像**：周报固定结构、用户反馈回写、月度总结与能力画像
- 🔌 **官方 SDK 长连接**：基于 `lark-oapi` WebSocket，**无需公网域名与内网穿透**
- 🗣 **意图路由**：直接说人话即可触发对应服务，超出范围会礼貌回绝

## 2. 功能介绍与特点

### 2.1 功能一览

| 能力 | 说明 |
|---|---|
| 日报记录 | 每日 22:00 推送填写卡片（分点填写、本周目标自动带入、昨日示例可展开） |
| AI 整理 | 要点串联成句、单句 ≤35 字；AI 不可用时回退原始表达，数据不丢 |
| 关键缺失追问 | 产出过于笼统时追问一次，补充后自动重新整理 |
| 确认闭环 | 确认存档 / 填意见重新生成 / 未操作默认保存（当日 23:59 标记超时自动保存） |
| 周报生成 | 每周六 22:00 汇总本周日报 + 本周目标 → 固定结构周报 + 能力评分 |
| 用户反馈 | 反馈卡片（准确性 / 是否有帮助 / 补充意见）→ **只回写反馈字段，不改历史原始数据** |
| 月度画像 | 汇总当月周报 → **月度总结（工作总结 + 能力分析）** + 五维能力评分，写入能力画像表 |
| 目标与规范 | AI 拆解候选周目标 → 用户确认后写入；工作规范注入周报提示词 |
| 意图路由 | 「写日报 / 查昨天日报 / 整理周报 / 看画像 / 建议下周目标 / 工作规范」等直接触发 |
| 数据与备份 | 5 张多维表格为云端主库；本地 JSON 记录级备份 + 全量快照 |

### 2.2 设计特点

- **程序与 AI 分工明确**：定时、校验、聚合、防重、周期计算交给程序；理解、表达、分析交给 LLM
- **原始数据与 AI 结果分离**：用户原文与 AI 整理分别落库，可追溯
- **用户反馈优先**：反馈独立存储，不覆盖任何历史事实
- **AI 不虚构**：提示词与解析层双重约束，未提供的信息一律留空
- **MVP 优先**：单用户、无前端、无 Multi-Agent / RAG / 复杂 Memory

### 2.3 在飞书里这样说

```
你好               → 一句话自我介绍 + 能力清单
写日报             → 推送当日日报填写卡片
查昨天的日报       → 返回日报卡片 + 表格记录链接
整理周报           → 汇总本周日报生成周报（带反馈表单）
看本周的周报       → 返回周报卡片 + 链接
个人画像查询       → 返回最新能力画像 + 链接
生成月度画像       → 生成月度总结与画像
建议下周目标       → AI 候选周目标，点选即写入
工作规范是什么     → 返回团队周报格式与要求
帮我订张机票       → 礼貌回绝并说明产品能力边界
```

## 3. 快速开始

### 3.1 环境准备

```bash
conda create -n yomi python=3.12 -y
conda activate yomi
pip install -r requirements.txt
```

### 3.2 配置

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

需填写：飞书应用凭证、多维表格 base 与 5 张表 ID、接收人 `open_id`、LLM Key。

> 飞书端配置（自建应用、权限、**长连接**事件与卡片回调、5 张表结构）见
> [docs/飞书端配置步骤.md](docs/飞书端配置步骤.md)。
> 长连接模式**无需公网域名或内网穿透**，仅需本机可访问外网。

### 3.3 启动

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

启动后会自动建立飞书长连接，并注册 5 个定时任务。健康检查：`GET /healthz`

### 3.4 定时任务

| 任务 | 时间 | 说明 |
|---|---|---|
| 日报卡片推送 | 每日 22:00 | 当天已填写则自动跳过 |
| 日报确认超时收尾 | 每日 23:59 | 待确认 → 超时自动保存 |
| 周报生成与推送 | 每周六 22:00 | 汇总本周日报 → 周报 + 反馈卡片 |
| 周报反馈超时收尾 | 每日 23:59 | 超窗口 → 无反馈(超时) |
| 月度能力画像 | 每月 1 日 22:00 | 生成上一月总结与画像 |

### 3.5 验证与运维脚本

```bash
pytest tests -q                                  # 单元测试（47 项）
python -m scripts.e2e_check                      # MVP 闭环自检（6 个环节）
python -m scripts.manual_trigger daily --dry-run # 手动触发（daily/weekly/portrait）
python -m scripts.seed_demo --dry-run            # 演示数据（--reset 清空后重建）
python -m scripts.backup                         # 全量备份到 data/backups/
```

## 4. 项目结构

```
YoMi/
├─ app/
│  ├─ main.py              # 应用入口：FastAPI、生命周期、依赖装配、回调分发
│  ├─ scheduler.py         # 定时任务：日报 / 周报 / 画像 / 超时收尾
│  ├─ ai/                  # LLM 客户端、提示词、结构化输出解析
│  ├─ core/                # 配置、周期计算、字段校验、日志、异常
│  ├─ data/                # 表结构定义、多维表格读写、本地备份
│  ├─ feishu/              # 官方 SDK 封装、卡片组件、长连接
│  ├─ routes/              # 可选 HTTP 回调（长连接模式无需）
│  └─ services/            # 业务编排：日报 / 周报 / 画像 / 目标 / 路由 / 查询
├─ scripts/                # 手动触发、演示数据、备份、端到端自检
├─ tests/                  # 单元测试
├─ docs/                   # 飞书端配置步骤等文档
├─ data/                   # 运行时目录：日志 / 备份（不入库）
├─ .env.example
├─ requirements.txt
└─ README.md（英文，默认）/ README.zh-CN.md（中文）
```
